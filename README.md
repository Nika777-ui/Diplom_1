# Diplom_1: Автотесты для Stellar Burgers

## Задание 1: Юнит-тесты

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы юнит-тесты, покрывающие клас:
- `Burger` - тесты для модели бургера (основная логика)

### Реализованные тесты
- set_buns() - установка булки
- add_ingredient() - добавление ингредиента
- remove_ingredient() - удаление ингредиента
- move_ingredient() - перемещение ингредиента
- get_price() - расчет цены
- get_receipt() - формирование чека

### Особенности реализации
- **100% покрытие** класса Burger
- **Моки** для изоляции от зависимостей (Bun, Ingredient)
- **Параметризация** для тестирования разных сценариев
- **Тестовые данные** вынесены в отдельный модуль `tests/data/`
- Всего: 18 юнит-тестов

### Запуск тестов
```bash
# Все тесты с отчетом о покрытии
pytest --cov=praktikum.burger --cov-report=html

# Проверить покрытие
pytest --cov=praktikum.burger --cov-report=term-missing

**Процент покрытия: 100%**

### Использованные технологии и подходы

- **pytest** - фреймворк для тестирования
- **pytest-cov** - инструмент для измерения покрытия кода
- **unittest.mock** - моки для изоляции зависимостей
- **Параметризация** - тестирование различных сценариев цен и данных
- **Юнит-тестирование** - тестирование отдельных компонентов системы

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов с отчетом о покрытии**

> `$ pytest --cov=praktikum --cov-report=html`

**Запуск автотестов с детальным отчетом в терминале**

> `$ pytest --cov=praktikum --cov-report=term-missing`

**Простой запуск тестов**

> `$ pytest`

После запуска с опцией `--cov-report=html` открой файл `htmlcov/index.html` в браузере для просмотра детального отчета о покрытии.
